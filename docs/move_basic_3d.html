move_basic.py를 3D로 따라가기

두산 E0509 로봇팔을 움직이는 ROS 2 노드를 코드 순서대로 설명해요. 스크롤하면 3D 장면이 지금 읽는 부분으로 바뀌고, 실행 중인 코드 줄이 강조돼요. 장면은 마우스나 손가락으로 돌려 볼 수 있어요.

1 import · 1–4줄

프로그램이 쓸 도구 가져오기

파일 맨 위에서 네 가지 도구를 불러와요. 3D 장면에서는 import 줄이 하나씩 실행될 때마다 도구 블록이 파일로 들어와요.

  • time 파이썬 기본 모듈이에요. 그리퍼가 움직이는 동안 time.sleep()으로 기다릴 때 써요.
  • rclpy ROS 2를 파이썬에서 쓰게 해 주는 라이브러리예요. 노드를 만들고 서비스를 호출할 때 필요해요.
  • DR_init 두산 라이브러리의 설정 저장소예요. 로봇 ID, 모델, 노드를 넣어 두면 나중에 DSR_ROBOT2가 꺼내 써요.
  • Trigger ROS 2 기본 서비스 타입이에요. 요청은 비어 있고, 응답으로 success와 message가 와요.
2 로봇 설정 · 6–9줄

어떤 로봇에게 명령할지 정하기

ROBOT_ID와 ROBOT_MODEL을 DR_init의 서랍에 넣어요. 3D 장면에서는 카드 두 장이 서랍 id, model에 들어가요.

  • dsr01 두산 드라이버를 켤 때 쓰는 기본 이름이에요. 드라이버의 토픽과 서비스가 /dsr01/... 아래에 만들어져요.
  • e0509 로봇 모델명이에요. 모델마다 관절 한계 같은 값이 달라서 정확히 적어야 해요.

장면 속 토픽·서비스 이름 가운데 (예시)라고 적힌 것은 드라이버가 만드는 이름의 예시예요. 실제 목록은 ros2 service list로 확인하세요.

3 조절할 값 · 11–16줄

왕복 거리와 속도 정하기

동작을 바꾸고 싶을 때 보통 이 여섯 값만 고치면 돼요. 아래 슬라이더를 움직이면 3D 장면의 P2 위치가 바로 바뀌고, 재생하면 그 속도로 움직여요. 여기서 바꾼 값은 5번, 6번 장면에도 그대로 쓰여요.

VEL과 ACC의 두 번째 값(deg/s, deg/s²)은 회전 속도예요. 이 코드는 자세를 바꾸지 않으니까 직선 속도인 첫 번째 값만 움직임에 영향을 줘요. 처음 실제 로봇에서 돌릴 때는 속도를 낮게 두세요.

4 call_gripper · 19–32줄

그리퍼 서비스를 부르는 함수

그리퍼에게 “닫아”, “열어”를 보내는 함수예요. 서비스를 찾고(최대 3초), 요청을 보내고, 응답을 기다리고(최대 5초), 결과를 확인한 뒤 GRIP_WAIT만큼 기다려요.

  • call_async는 응답을 기다리지 않고 바로 future를 돌려줘요. future는 “나중에 결과가 들어올 상자”예요.
  • spin_until_future_complete가 노드를 돌려야(spin) 응답 메시지가 실제로 처리돼요.
  • 서비스는 명령을 받자마자 응답할 수 있지만 집게가 다 움직이려면 시간이 걸려서, 마지막에 time.sleep으로 기다려요.

아래에서 상황을 골라 보세요. 실패하면 어떤 에러가 언제 나오는지 볼 수 있어요.

이 코드는 서비스를 호출만 해요. /dsr01/gripper/open, /dsr01/gripper/close를 제공하는 노드는 따로 실행해야 해요.

5 main · 35–71줄

로봇을 실제로 움직이는 main 함수

노드를 만들고, 두산 함수를 가져오고, 자동 모드로 바꾼 뒤 지금 위치를 P1로, 옆 점을 P2로 정해요. 그다음 movel로 P1↔P2를 REPEAT번 왕복하고, 그리퍼를 닫았다가 열어요.

  • DSR_ROBOT2는 import되는 순간 DR_init.__dsr__node를 가져다 써요. 그래서 노드를 만든 뒤에 main 안에서 import해요.
  • movel은 끝단을 직선으로 움직이고, 도착해야 다음 줄로 넘어가요. 3D에서 끝단이 남기는 선과 속도 그래프로 확인할 수 있어요.
  • 장면 아래의 Ctrl+C 버튼은 try 블록이 실행되는 동안 눌러 볼 수 있어요. except와 finally가 어떻게 동작하는지 보여 줘요.

3D 장면의 시작 위치 [400, 0, 400, 0, 180, 0]은 예시 값이에요. 실제로는 로봇이 서 있는 위치에서 시작해요. 받침대 위 큐브도 잡기 동작을 보여 주려고 놓은 예시예요.

6 실행 진입점 · 74–75줄

프로그램이 main()에 들어가는 두 가지 길

python3 move_basic.py로 파일을 직접 실행하면 __name__이 "__main__"이 되어 74–75줄이 main()을 불러요. ros2 run robot_control move_basic으로 실행하면 setup.py의 entry point(move_basic = robot_control.move_basic:main)가 main을 바로 불러서, 이 두 줄은 쓰이지 않아요.

실제 로봇에서 실행하기 전에 두산 드라이버(bringup)가 켜져 있고 주변에 사람이나 물건이 없는지 확인하세요. 프로그램을 멈춰도 컨트롤러가 이미 받은 이동은 끝까지 진행될 수 있으니, 급할 때는 티치 펜던트의 비상 정지를 쓰세요.
