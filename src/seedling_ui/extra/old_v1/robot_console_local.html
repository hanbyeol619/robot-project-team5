  1. 빈 영역 판별카메라로 칸 확인
  2. 간격 계산심을 칸 고르기
  3. 묘목 식재집어서 옮겨 심기
  4. 결과 확인다시 촬영해 검증

간격을 160mm보다 크게 잡으면 옆 칸과 너무 가까운 칸은 “간격 부족”으로 건너뜁니다. (칸 사이 거리는 약 160mm로 가정)

작업 명령은 반드시 “승인” 후에만 실행됩니다. “멈춰”는 승인 없이 바로 일시정지합니다. 로봇에 연결하면 마이크 버튼은 녹음 버튼이 됩니다. 한 번 눌러 말하고 다시 누르면 Whisper가 글자로 바꾸고 Claude가 해석합니다. 시뮬레이션 모드의 해석은 간단한 규칙으로 흉내 낸 것입니다.

아직 분류하지 않았어요.

고정된 모형 열매를 색으로 빨강(익음)과 초록(덜 익음)으로 나눕니다. 분류가 끝나면 지도에 결과와 확신도가 표시됩니다.
